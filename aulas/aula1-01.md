Aula 01 — Introdução ao GitHub
Na primeira aula, aprendi o que é o Git e o GitHub e para que eles servem. Aprendi que o Git é usado para controlar as versões de um projeto e que o GitHub permite guardar arquivos online e trabalhar em equipe.
Também conheci os repositórios, o README e os commits, que servem para registrar as alterações feitas nos arquivos. Foi uma aula importante para entender como organizar um projeto e acompanhar seu desenvolvimento.
