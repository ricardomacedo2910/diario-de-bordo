Aula 02 — Checklist de Aprendizagem
O que já domino:
Criar um repositório no GitHub.
Editar arquivos pela interface web.
Escrever títulos e textos usando Markdown.
Fazer commits para salvar alterações.

O que falta estudar:
Criar e trabalhar com branches.
Abrir Pull Requests e revisar alterações.
Resolver conflitos entre branches.
Organizar tarefas usando Issues e Projects.
Aprender mais comandos do Git.
